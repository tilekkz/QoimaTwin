# M14 — Анимируемый погрузчик

Финальная модель: `assets/v3/blender/forklift.blend`, `frontend/public/models/v3/forklift.glb`. Масштаб1:1,1.2×2.1×3.0м,Yвверх,+Zвперёд.68замкнутых объёмных деталей,11шарниров,14опорных точек. Шасси/колёса/кабина связаны реальными соединениями, мачта имеет направляющие/ролики, каретка выдвигается на0.4м, вилы цельные со сквозными отверстиями.

Все6погрузочных типов груза проверены в18позах. Длинномер: отдельное Uоснование3.2×.15×.85, реальные карманы/стопоры и съёмные верхние скобы. Закрытые компоненты укладываются в неизменные C08габариты. При разгрузке фиксаторы извлекаются над опорами стеллажа, скобы снимаются, груз ставится на опоры, основание опускается на20мм и выходит. Эта геометрия не подменяет будущие действия персонала.
