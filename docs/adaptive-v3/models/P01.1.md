## Joint/anchor contract

15 rigid joints: pelvis → torso → head; парные upper_arm → forearm → hand и thigh → shin → foot. Все bind rotations — identity в runtime XYZ; только meshes получают собственные basis. L находится в−X. Для зеркальной позы Euler XYZ знаки `(1,-1,-1)`, без отрицательного object scale. JSON хранит world и parent-local positions, ограничения в радианах; будущий builder использует проверенные `pivot/anchor` helpers.

Правая цепочка (левая зеркальна): shoulder `(.215,1.105,0)`, elbow `(.265,.905,.01)`, wrist `(.300,.715,.025)`; hip `(.095,.595,-.005)`, knee `(.105,.365,.005)`, ankle `(.115,.14,-.005)`. Torso pivot `(0,.675,-.005)`, head pivot `(0,1.195,.005)`.

Семь физических anchors: floor `(0,0,0)`, neck-base `(0,1.15,.005)`, seat-contact `(0,.55,-.035)`, grips `(±.307,.665,.075)`, soles `(±.115,0,0)`. Sole patches находятся внутри плоских оснований ботинок. По расчёту14суставных соединений сохраняют положительный общий объём: консервативный радиус общей области после фаски не меньше7 мм. Это обещание конструкции кубоидов, не приёмка ещё не построенных стыков.

## Материалы и граница приёмки

`V3_Worker_RoleVest` и `V3_Worker_RoleHeadwear` — единственные role-tint slots. Blue/orange/purple/green/yellow берутся из принятого manifest; shirt/trousers/boots остаются тёмными shared slots. Пять badge codes01…05 — коды ролей, не actor_id; ID не запекается в геометрию. Материалы клонируются на экземпляр в будущей P02, глобальное перекрашивание запрещено.

Фактически выполнены только pure-Python checks: рост/границы,7mirror pairs,15parent reconstructions,24правых part frames,14joint overlaps,11vertical contact intervals, reach и seat-fold screen. Geometry, Blender, renderer/browser не запускались. Root принимает размерный план перед P01.2; внешний вид/GLB/poses остаются обязательными отдельными gates.
