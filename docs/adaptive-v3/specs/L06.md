## Топология и метрический cost

Граф содержит **51 nodes, 54 physical edges, 108 directional arcs**. Каждое physical edge записано один раз с `direction:both`. Все рёбра ортогональны X/Z, Y=0; `length_m` и `cost_m` равны фактической длине. Сумма physical lengths 622.9 м — длина graph geometry, не трудозатраты/пройденный путь персонала.

Основные линии: X6/72/138 и Z10/38/66. Пересечения и обязательные endpoints детерминированно разбивают линии; stable IDs привязаны к exact centimetre coordinates/service IDs, edges сортируются по координатам. Random/layout scaling не применяется.

| manual_cart | radius 0.95 м / diameter 1.90 м для combined cart+operator assembly | 2.0 м corridor; 1.0 м/с | Anchor — центр conservative assembly envelope, не model cart origin; exact rig/loaded checks позже |

Widths/speeds — synthetic assumptions. Полоса 2.0 м является проверенным нижним clear envelope graph edge, не заявленной шириной всего warehouse corridor. Future collision/resource scheduling должно учитывать встречных людей/тележки; reachability не даёт разрешения двум assemblies занять одно место одновременно. Forklift/heavy-load dragging запрещены на этом графе; vehicle graph — L07.

## Packing integration с root L08

PK01–PK06 имеют X62/73/84/95/106/117. Для каждого прямая collinear ветка: corridor Z10 → cart assembly stop Z7.2 → pedestrian service Z6.1. Первые 2.8 м допускают оба режима; последний 1.1 м — только pedestrian. Cart-mode routing до конечного service node возвращает no_path, до cart stop — корректный путь.

Две явные reservations внутри L02 PACKING_LIGHT_LINE: north strip X54–132/Z6–8 для обоих режимов и human-only terminal apron X54–132/Z5.7–6. Tables/conveyor root L08 ограничивает Z≤5.7. На terminal full 0.70 м envelope достигает min Z5.75, nominal gap 0.05 м до cap; cart full 2.0 м envelope у stop достигает minZ6.2. Это численный synthetic clearance, не проверка будущего mesh/animated limbs.

Cart stop — transient graph endpoint, не permanent parking, storage slot или дополнительный buffer. Переход к table/service выполняется пешком; будущая workflow/rig integration задаст release/grip/parcel transfer. Conveyor near Z3 не пересекается этим graph plan; protected express approach остаётся свободным.

## Проверено фактически

Independent direct JSON re-read: **950 checks, 0 failures**. Проверены positive orthogonal lengths, unique IDs/endpoints, explicit direction/modes, mode widths/speeds, полный buffered rectangle каждого edge против разрешённого clear-floor union и отдельный 0.25 м sampling по всей длине, ширине и end caps — **52,452 samples**. Storage/staging/reserve intersections отсутствуют. Packing reservations — единственное explicit исключение из L02 circulation.

Все 51 pedestrian nodes и 45 cart-eligible nodes связаны. Проверены 6 exact port services, 10 external gateways, 6 pedestrian packing services и 6 cart stops. Для всех 15 port pairs в обоих режимах shortest path непрерывен, reverse cost совпадает, cost равен сумме фактических edge lengths.
