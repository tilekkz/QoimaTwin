## Packing witness и model semantics

Для каждого HU сохранены explicit inner bounds и все individual unit min/max envelopes, count/grid/gaps. Проверены все3оси, размеры каждого unit, containment, nonoverlap и count; равенство суммарного объёма не заменяет fit. Всего107prototype instances относятся к одному образцу каждого из8HU, не к warehouse inventory.

Grid gaps имеют явную support convention: нижние units опираются на localized integral packing/dunnage на recorded lowest_unit_bottom_y, верхние aligned columns — через units и separators толщиной inter-layer gap. Это не floating contents и не solid full-volume slab; dunnage/separator mass уже входит в outer HU tare. Strength/contact approval остаётся downstream, и эта внутренняя упаковка не добавляет смещение всему HU над slot support.

Recipe frame — minimum outer HU XYZ corner. HU model origin — floor centre XZ/Y0; координаты переводятся как (x−HUwidth/2,y,z−HUdepth/2), scale1. Interior glyphs — содержимое HU, а не дополнительные lots. На LONG остаются24real4m profile envelopes внутри4.2m bundle; нельзя уменьшить его для узкого slot.

IBC/DRUM имеют по одному physical primary container. Их жидкости описаны отдельной symbolic convention: IBC600kg при assumed1000kg/m³ =.60m³ fill, synthetic declared capacity.65m³; DRUM160kg =.16m³ fill при declared capacity.18m³. Это sealed-content/fill-indicator convention, не600/160box units и не утверждение внутреннего mesh volume. Контейнерный unit envelope помещается в outer cage/support; actual interior geometry/handling остаётся downstream gate.
