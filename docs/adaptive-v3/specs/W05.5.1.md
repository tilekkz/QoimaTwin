# W05.5.1 — Browser action-source package

The W05.1 factory verifies actual source bytes. A production browser cannot read repository paths. This prerequisite maps exactly30accepted dependencies to normal project-relative static URLs:20existing public sources remain in place;10explicitly allowlisted proof/source documents have exact hashed copies (39439bytes total). `build_action_browser_sources.py` pins the four accepted base documents, existing registry source hashes and six W04 support bindings. It refuses undeclared private/nonpublic paths, path escapes, byte/digest drift and oversize sources. It writes only the bundled manifest and owned proof copies, with UTF8/LF deterministic metadata and atomic replacement. `--check-only` compares output bytes without writes. It does not remove unrelated files.

`createWarehouseActionSourceReader({fetcher?,signal?,timeout_ms?})` returns `readSource`, `snapshot` and idempotent `dispose`. Importing it has no network, timers, renderer or scene effect. The bundled allowlist is snapshotted privately. Fetches use project-relative URLs; returned bytes have exact source size andSHA256. Stream reading refuses excess bytes; deadlines apply through response/body/hash completion. Each reader deduplicates inflight work and caches only verified bytes; returned copies cannot corrupt its cache. Failure can be retried. Abort/dispose cancels owned requests and clears cached bytes, including late completion by a fetch implementation that ignores its signal.

Independent review exposed a late-response body lock after cancellation, and cleanup that could mask an oversize refusal. The reader now cancels late response bodies before acquiring a reader, checks an already-aborted signal when attaching reader cleanup, and never awaits unbounded/rejecting cancellation. Extra regressions verify actual stream cancellation/unlocked bodies after dispose and timeout, plus unchanged integrity reasons under rejecting or never-finishing cleanup.

After `npm run build`, the gate registers a real W05.1 catalogue through actual native fetch/HTTP/streaming from all30normal production static URLs on an owned ephemeral localhost server, then closes that server. It also checks optional support bytes, source/hash/size/HTTP failures, dedup/cache/copy isolation, retry, bounded timeout, external abort, pre-abort and idempotent disposal. Run `node tools/check-warehouse-action-sources-v3.mjs`; `--check-only` repeats the meaningful tests and compares evidence without writing it (ignored transpile cache is regenerated). This packages already accepted source evidence; it does not add physical action joins, a backend adapter, jobs, inventory changes, automatic playback or operational availability. Actual warehouse UI integration remains W05.5.
