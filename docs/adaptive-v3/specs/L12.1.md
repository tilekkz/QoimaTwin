# L12.1 — versioned semantic index

Статус: VERIFY, root review pending. Изолированный schema_id=qoima.layout-semantic-index.v3-proposal, schema_version=0.1.0, layout_version=qoima-144x72-v3-proposal. Stage только semantic_index_only; это proposal, не общий backend contract и не runtime package.

layout-semantic-index-v3.json сохраняет исходные IDs,15 точных source SHA256/byte lengths и отдельные массивы definitions/references. Каждая запись указывает source_id и RFC6901-style JSON Pointer; source table раскрывает полный repository-relative path. Компилятор — tools/visual/v3/compile_layout_v3.py. Existing/shared/V2/backend inputs не переписываются.

Метры, секунды, килограммы, radians, Y-up/right-handed; bounds[0,0,0]…[144,8,72], minimum-floor-corner origin, entity scale1. L10 stats/GLB входят в fingerprints как diagnostic engineering assets, а не новый источник semantic IDs. Canonical V2 actor file используется только для проверки24 identity values: старые позиции, home nodes и роли не импортируются в V3 layout.

## Определения и ссылки

Identity key — (kind,id). Два определения в одном kind запрещены даже при равных payload. Повторное упоминание в другом файле является reference с собственным pointer, а не вторым определением.

Шесть v3:service:PORT_ID намеренно присутствуют как ped node и vehicle node. Это разные typed definitions, связанные с одним service_place, определённым соответствующим портом. Все три source world positions должны совпасть. Yaw, permissions и graph identity не объединяются. L08 три handoff nodes и три новых junction nodes проиндексированы как proposed pedestrian definitions; они ещё не присоединены к графу.

Индексирует declared live entity tables и material relationships:

- зоны/порты/service places/buffer cells,24actors/2pools/2pairs/2vehicles;
- L05 blueprint/cradle/orientation, L06/L07 nodes/edges/profiles/reservations;
- L08 conveyor nodes/edges/modules/cells/resources/6packing stations;
- L09 132modules/776slots/844local services/844local paths/5storage families;
- L11 282traffic resources и1234audit route refs с исходными typed edge/path/handoff targets.

Итого **5081 definitions и23774 references**, duplicate/missing/provenance mismatch0. Все132module и776slot IDs взяты из L09, не сгенерированы заново. Восемь R03 cargo IDs имеют kind cargo_reference_target; это reference targets pending C02, не SKU/lot/catalog admission. Два явно помеченных derived enum definitions — существующая L09 upright orientation и declared forklift mode. Free-text guards, negative fixtures/case labels, assumption labels и L10 mesh-node names не повышаются до live entities.

## Проверки и следующий этап

Actual generation exit0; --check-only сравнивает полное deterministic byte representation с сохранённым index без записи inputs/outputs. Валидация разрешает каждую ссылку внутри typed namespace и повторно читает все definition/reference source pointers. Exact source hashes проверяются до/после компиляции.

Четыре actual in-memory negative cases:

1. Добавление дубликата slot в source table → DUPLICATE_DEFINITION.
2. Подмена source slot.module_id отсутствующим ID → MISSING_REFERENCE.
3. Подмена P01 на P99 при сохранении headcount24 → ACTOR_IDENTITY_MISMATCH.
4. Смещение vehicle service position на0.1м при прежнем ID → SHARED_SERVICE_POSITION_MISMATCH.

Independent artifact checks и fingerprint результата находятся в evidence/L12.1.json. Reproduce: .venv/Scripts/python.exe tools/visual/v3/compile_layout_v3.py --check-only.

В L12.1 не создаются новые edges/adjacency, distances, simulation/admission или public manifest. Все L08 split intents и L09 graph/node/edge references сохраняют source provenance. L12.2 должен собрать все split points одного исходного L06 edge вместе, отсортировать один раз и сохранить оба направления/modes; vehicle fractions вычислять аналитически с независимым yaw. Это требование следующего gate, не уже выполненная реализация. L12.3 package/checksum gate также не начат. Root-owned density/lighting findings остаются открыты.
