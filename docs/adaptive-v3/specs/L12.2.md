## Все разбиения одного ребра — один проход

Walking split requests сначала группируются по original edge, проверяются на source segment, сортируются по u и лишь затем заменяют ребро целиком. Edge0015 получает u0.5. На edge0046 сохранены оба junctions:

- v3:ped-node:12975:01000, u0.607142857143;
- v3:ped-node:13125:01000, u0.678571428571.

Edge0046 превращается в три физических участка/шесть arcs с обоими исходными modes и directions. Сумма cost/length каждого направления равна original. Width/state/access restrictions сохранены. Coincident split requests объединяются без zero edges и потери source intents; несовместимая координата при том же fraction отклоняется. Proposed semantic aliases не превращаются в скрытые дополнительные рёбра.

Три L08 manual connectors присоединены к этим junctions. L09 manual paths сохраняют source waypoint geometry и declared mode; worker path соединяется с собственным explicit cart-stop semantic node перед pedestrian-only terminal. Никакие случайно совпавшие точки разных путей не соединяются только по координате.
