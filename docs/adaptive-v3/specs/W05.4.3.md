# W05.4.3 — Same-instance native pallet applicator

`createWarehousePalletTransferScene({bundle,catalogue,policy,plan,vehicle,actor,seated,bound,parts,onFrame?,invalidate?,signal?})` consumes the issued W05.4.1 plan and the identical bundle/catalogue/policy. Its private Scene inputs are the existing FL02 group, existing F02 worker and seated binding, original source `BoundCargo` and its actual `CargoMeshPart[]`. It creates no geometry, material, scene node, worker or HU.

The returned API is `apply(absoluteSeconds)`, `snapshot()`, `reset()`, idempotent `dispose()`, guarded `releaseAtEnd()` and `forkSupportParts`. Construction captures each actual GPU instance world matrix and recovers the HU root with `instanceWorld * inverse(sourceMatrix)`. It temporarily poses the native reach at attachment, captures `inverse(reachWorld) * HUroot` plus per-part corrections, computes the release frame, then restores all native local transforms before returning. There is no callback or render during construction. Neither a hardcoded .6 translation nor a yaw-zero holder is used.

`isWarehousePalletTransferScene(value,bundle?,plan?)` checks private controller issuance and optional exact source identities. A structural controller copy, null binding or a different source object cannot pass a supplied identity check. This is an issuance guard, not a native-admission or active-lifecycle claim; closed controllers still reject apply/reset/release. `PalletTransferFrame` is exported for the root gateway.

Absolute seeks restore saved native binds before applying body/carriage/reach/fork/rear-steer/wheel controls. The existing seated actor stays parented and posed; the static steering-wheel grip pose is retained while the actual rear steering joints follow the plan. Only selected instance slots change. Shared mesh origins, source matrices, geometry/material/UUID/index and other HUs remain unchanged. Actual Float32 instance writes are inspected for coherence and a two-micrometre translation budget. This is a numerical continuity check, not collision or physical admission.

Each applied immutable frame exposes one coherent `bound`, `logical_owner`, actual `native_root_matrix`, captured `reach_relative_matrix`, per-part root spread, instance identities and the existing seated binding snapshot. `onFrame(frame)` is the root-owned metadata gateway; `onFrame(null)` clears the override on reset/disposal. `invalidate()` requests root rendering. The original private cargo calculator is never mutated. Constructor-time semantic identity, start-frame, unit-scale, issued-plan and seated-driver checks precede ownership. Changed selected bindings/joints, invalid times and concurrent applicator ownership reject. Apply callback failure rolls native state back; abort restores and releases this applicator's ownership. Existing worker/binding/assets are never released or disposed by it.

`apply(0)`, reset and disposal restore original local transforms and selected Float32 source slots exactly. Reset leaves the applicator reusable. Terminal release requires the current exact terminal sample, relinquishes ownership and retains that pose/frame for a separate guarded root commit; it performs no stock commit, event, resource or job operation. Dispose after terminal release leaves the retained pose in place.

The dedicated gate uses actual GLTFLoader assets, source-bound plan/catalogue/policy and the original 530 HU identities, 24 workers and two vehicles without a WebGL renderer. It tests arbitrary/reverse/repeated seeks, attachment/release world continuity, native support exposure, coherent inspector metadata, foreign-buffer stability, nondefault shared-mesh representations, atomic refusals, callbacks, abort, exact reset and owned cleanup. Full native collision/C08 acceptance belongs to W05.4.2 and actual Scene/UI/browser acceptance remains a parent gate. `physical_join:false`, `native_geometry_admission_required:true`, `engine_operation:false` and zero completed jobs remain explicit.

Actual CPU result: 14 positive groups, 70 rejected cases, 143 absolute samples plus 286 reverse/repeated samples, and 38 samples with a nondefault shared mesh origin/rotation. A failed gateway call rolls back both native state and cached validation frames; a subsequent valid apply and reset succeed. Seat, both grips and both soles require finite nonnegative errors no greater than two micrometres. Independent actual native anchor offsets of 20 micrometres reject for seat, grip and sole; NaN and boolean contact summaries also reject. The original HU has five native instance parts and the applicator exposes the two actual fork meshes. An independent native hierarchy calculation verifies body, carriage, reach, fork spacing, rear steering, wheel spins and the captured per-part transforms. Maximum native-root translation error against that calculation is 1.8863 micrometres; every native part has zero measured attach/release matrix and translation difference at ±1e-7-second boundary probes. Maximum driver contact error is 0.0697 micrometres. No foreign resource is disposed.

Native Float32 corrections are retained and reported, rather than replaced by an ideal .6 translation. The captured reach-relative translation is approximately [0,7.15e-9,.5999997422] with relative rotation pi. Independent rounding of the five instance parts yields maximum recovered-root spread 2.7783 micrometres (2.5271 with the tested alternate representation), and maximum ideal-plan position drift 2.0987 micrometres. These are explicit representation limits; the two-micrometre continuity and actual instance-write budgets are separate checked quantities. Full native contact/obstacle admission cannot be inferred from those numbers. Evidence binds 56 relevant source/code/data/native asset inputs.

Run from `frontend`: `node tools/check-warehouse-pallet-transfer-scene-v3.mjs`, then `node tools/check-warehouse-pallet-transfer-scene-v3.mjs --check-only`. Only owned evidence and the ignored transpilation cache are written; check-only requires exact evidence bytes and unchanged mtime. Root alone accepts task status and performs integration/Git actions.
