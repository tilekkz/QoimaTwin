# W05.4.1 — Pure source-bound pallet transfer reference

API (available for root inspection):

```ts
compileWarehousePalletTransferPlan(bundle, catalogue, policy, request): PalletTransferCompilation
isWarehousePalletTransferPlan(value, bundle?, catalogue?, policy?): boolean
sampleWarehousePalletTransferPlan(plan, seconds): DeepReadonly<PalletTransferSample>
```

The request has exactly four string fields: `handling_unit_id`, `destination_slot_id`, `actor_id`, `vehicle_id`. Compilation requires the W05.1 issued action catalogue bound to that identical bundle and a W03 issued policy. It returns an immutable typed rejection or a privately issued immutable plan. Structural copies never pass issuance guards. `PalletTransferError` distinguishes invalid plan and invalid numeric time. No route, proof, cargo, duration, speed or transform overrides are accepted.

This bounded reference uses original F02/FL02 and the existing DEMO_172 HU. Target feasibility, source pair and exclusive source identities are checked before route minimization. A private cargo calculator supplies accepted storage poses and feasibility; its local reference binding never changes source stock or a Scene. W03 routes and preview timing are used directly. The accepted M14.8 closed 30-second clip remains unchanged and is not scheduled or split: its controls guide a new explanatory sequence.

All handling durations (including 0.25-second graph/fixture connectors) are explanatory assumptions. Native Float32 reach binds are an explicit reference assumption; later runtime must capture inverse(reachWorld) * HUworld. Relative yaw pi preserves source HU world yaw; W04 yaw-zero holder registration is not used. Every native orientation, driver, pallet, fork, contact, obstacle and C08 clearance admission remains pending in parent W05.4.

Body heading remains unwrapped across route and handling phases. The actual empty route ends at -3pi/2 after legitimate turning; all handling retains that raw heading instead of interpolating back to the equivalent pi/2 and making an unintended full turn. Loaded-route endpoints and samples share the same unwrapped offset. Wheel rolling offsets and the relative-pi pallet orientation are preserved; source and target HU world quaternions remain unchanged during handling.

Intervals are finite capacity-one, half-open, conservative whole-plan EXCLUSIVE planned references for original actor/vehicle/HU, target slot, both handling spaces and actual graph reservation group IDs. They acquire no resources and have no actual ledger, event or engine effect. Cost flags stay false; route distance minimization is geometric reference work only.

Reset to time zero is a deliberate seek back to the original stock reference, not a continuous spatial wrap or a second transfer. There is one HU identity and one logical owner per sample; the remaining 529 HUs, original 24 workers and 2 vehicles are unchanged. No animation boundary completes a job.
