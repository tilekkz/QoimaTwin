# C07 — exact mass ledger and handling

The [saved cases](../../v3/contract-proposals/cargo-mass-cases-v3.json) use the same C05 storage evaluator, extended with a Decimal mass ledger. `unitGross = contents + primaryTare`; `HUcontents = unitGross × integerUnitCount`; `HUgross = HUcontents + outerTare`. Non-finite/negative values, non-positive gross mass and boolean/fractional/zero counts reject. Supplied totals must match these identities before payload or handling acceptance.

The eight unchanged production HU gross masses are .94,6.35,200,455,654,200,180,88kg in C02 order. Unit and HU tare are distinct. An external LONG attachment is additional lifted equipment mass under C08; it is not added to unit count or silently absorbed into HU tare. Payload checks include existing module mass and slot occupancy. No count is inferred from a rendered box or a volume.

The manual15kg limit is a declared synthetic simulation rule. An isolated, explicitly hypothetical fixture raises slot payload to1000kg so that the handler boundary itself is tested:15kg passes,15.0001kg rejects `OVERWEIGHT` at `manual_handler`. This fixture does not modify a production SKU, cargo template or slot.

All six forklift-family production HUs retain forklift-only handling. Each has a positive design candidate, a forced-manual rejection and an absent-handler rejection. Reducing their dimensional fields in a negative fixture leaves all mass ledger values and forklift requirements unchanged; a smaller glyph cannot make a heavy HU manual. C09 must independently reject that production dimension override. Actual C08 support/attachment/rating/route and M/P mesh/contact proof remain required before a W operation.

Ten invalid ledger cases check omitted unit/HU tare, changed count/aggregate without corresponding mass, invalid counts, negative masses/tare and infinity. Run `.venv/Scripts/python.exe tools/visual/v3/verify_cargo_mass.py --check-only`. Affected C05/C06 strict checks also pass with their saved output bytes unchanged. No source template, shared contract, actor count or inventory is changed.
