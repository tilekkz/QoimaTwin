Для L07 берётся наибольший admitted component profile на каждом edge, включающий меньшие; L09 использует свой declared profile. Не допускаются spin/reverse yaw shortcuts.

Для каждого padded corner radiusρ относительно ICR используется дополнительная инфляция `ε=2ρ sin(Δθ/(4N))`; ближайший sample покрывает непрерывное движение между позами. ρ включает исходный padding0.25м. Проверяются SAT against actual convex obstacles и allocated-floor keep-outs, building bounds, profile permissions, declared width/height. Reverse/source links сохраняются; детерминированные travel durations или traffic behavior здесь не создаются.

## Mixed traffic — вход будущего W scheduler

282 namespaced resources `v3:traffic:cell:XX:ZZ` размером4×4м имеют `capacity_occupants=1`, human/vehicle route references и profile/mode membership. `route_ref_index` явно связывает audit refs с L06/L07/L08/L09 source IDs. Учтены crossings, parallel shared corridors и совместные endpoints; проверить только X-перекрёстки было бы недостаточно.

Регистрация консервативна: human capsule пересекается с whole vehicle-component sweep hull, затем область распределяется по клеткам. Arc hull и cell quantization могут резервировать лишнюю площадь; они не разрешают движение и не утверждают точное столкновение в каждой клетке. Proposal требует совместного atomically ordered резервирования этих пространственных ресурсов и уже существующих vehicle/port/work resources. Реальные grants/waits/deadlock policy/release times — отдельная работа W/backend. `scheduling_implemented=false`, `operational_admission=false`.

Сохранены24 actual actor IDs, общие R01/R02 и S01/S02 pools, только пары F01/FL01 и F02/FL02. Пространственные ресурсы не добавляют людей или погрузчики. Регистр не утверждает работоспособный engine run либо throughput.
