# W05.2 — Grounded unloaded worker travel primitive

This is a new source-bound visual motion controller on the existing canonical worker instances. The 16 accepted prepared clips, their durations and all source models remain unchanged. In particular, the accepted nine-second/.84m cart demonstration is not used or rescaled. Warehouse viewer/unified clock integration remains W05.5; no cargo, stock operation or job completion occurs here.

## API

`await createWarehouseWorkerWalkContext(bundle, issuedActionCatalogue, issuedRoutePolicy, existing24Workers, readSource)` verifies the identical W05.1 bundle/catalogue, 24 unique registered WorkerInstances, and SHA-bound worker-base/manual GLB bytes. It parses the native bodies solely to extract immutable joint/bind/sole calibration, then disposes those unmounted calibration resources. It adds no worker or scene model. Only those two GLB paths are required, already present in the action source catalogue. Original joint metadata supplies all 15 body limits; no new role/vehicle limits are declared.

`context.compile({actor_id, from_node_id, to_node_id, closed_arc_ids})` calls the accepted W03 pedestrian router. It accepts no cargo, cart, scale, speed, duration, position or heading override. The actual existing actor must stand at the source node in source rest pose and world scale one; its actual initial world yaw is captured. Two assigned seated drivers are refused until a separate physical dismount is admitted. Profile eligibility does not grant a new current role.

The result contains typed admission and a privately issued immutable travel plan. Its `duration_s`, phases and absolute `sample(t)` are distinct from prepared RoleClip records; no fake clip ID is introduced. A later clock can reserve that actor for the derived interval and call this primitive at local absolute time.

`createWarehouseWorkerWalk(existingActor, plan)` binds that same object and exposes `apply(t)`, `snapshot()`, idempotent `dispose()` and `releaseAtEnd()`. Apply zero and dispose restore the exact captured source transforms/quaternion, including original arms and heading. Random seeks derive all targets from the finite source plan, not prior footfalls. The terminal frame is rest pose at the target source node. `releaseAtEnd` is guarded to that terminal frame and releases the gait binding while preserving its physical end frame for a later action; it does not complete a job. Disposed, role-changed, reparented, rescaled or externally edited actors invalidate motion. Dispose restores the captured original parent and root/joint scales as well as position/quaternion, including after external pose invalidation. Context disposal releases its active walkers.

## Motion assumptions and native gate

Original source arms remain unchanged throughout. Preparation/settle take .35s. Before heading alignment, each foot steps outward in sequence without root yaw, to a temporary stance half-width derived from the actual native sole X/fore-aft corners and the separating-axis support at adjacent headings, with2mm reserve. Both feet gather to original stance after turning. This prevents the foot/foot penetration detected in the earlier unprepared stance; that failed native witness is preserved in evidence as historical, never current acceptance. Heading alignment uses finite <=15 degree flat-foot stepping turns, .32s per swing plus a final foot gather. If the actual native rest radial extent does not clear fixed source module bounds at the original node, a backward retreat is allowed only along the same admitted first edge when that edge is directly opposite the actual source heading. The endpoint is the first centimetre interpolant whose entire source body radial envelope plus2mm clears those fixed bounds; it is not a graph node or shortcut. It must fit inside that original first edge. The retreat uses a separately declared <=.35m/s cap, stops, gathers the feet, then turns; its distance is subtracted from the remaining original edge. P01 bare-context source geometry derives .03m retreat and .3885771343902948m turn clearance radius. Insufficient clearance or a non-backward tight edge is refused. No arm narrowing or body scale change is used.

Each stance sole retains one unchanged world position and yaw. Swing feet lift by a declared .018m profile. Translation follows original source segments, merging only collinear contiguous edges; it never cuts a corner. P11 1.2m/s is the forward cruise cap, with declared .8m/s2 acceleration/deceleration. Step advance is at most .22m, with both feet gathered at each stopped corner/end. Pelvis drop derives from actual rigid leg lengths/foot targets; body geometry is neither scaled nor stretched.

Each sampled pose solves native three-dimensional thigh/shin/foot chains and preserves source joint positions and all original angular limits. Actual native sole vertices and anchors are inspected after applying to the unchanged actor. The compiler additionally samples entire native rotated-body vertex bounds against source storage-module outer bounds and the warehouse floor/envelope. This is conservative and can refuse a route whose outer-bound overlap has not been independently admitted; it is not a continuous collision certificate.

The current materialized C01 is at P01's only original exit/cart node. If the action catalogue declares C01, P01's nonempty original source exit is conservatively refused with `FIXED_EQUIPMENT_STATE_REQUIRED` until trusted actual equipment/dynamic closed-arc admission is provided in integration. No cart is moved and no bypass edge is invented. A bare context without materialized C01 can independently test the rack-adjacent source turn, but that is not acceptance of walking through the current parked cart.

## Identity, effective matrix and ancestor guards

The compiler accepts only a closed own-data-property request with the four documented fields. It inspects descriptors without invoking ordinary property/array accessors, rejects symbols and unsupported prototypes, and copies primitive actor/node/closed-arc IDs into one private frozen request. All worker, registry/profile, route and C01 decisions use that stable identity. Foreign requests/arrays are not frozen or retained.

The accepted native rig requires automatic, coherent local and world matrices. The loader records original update flags from the unchanged GLB. Before compilation, binding, live sampling and terminal release, validation checks native hierarchy/object identity, effective local matrices against TRS, effective world matrices against their parent chain, source geometry/limits, and the captured ancestor frame. Manual matrices and disabled update flags are unsupported. An unchanged `position`/`quaternion` cannot hide a translated native mesh or joint. Ancestor translation, rotation, scale, reparenting or render-matrix changes invalidate the action frame.

Owned pose capture includes the root and all original descendant TRS, effective local/world matrices, matrix update flags and parents. Discard restores those owned fields, reconnects original native nodes, detaches unowned additions without disposing them, and remains idempotent. It does not rewind an externally moved warehouse ancestor; the caller must restore that unowned coordinate system before using the context again. Terminal release additionally verifies the actual world root, heading and native sole targets against the issued endpoint. No job completion or new operational grant is introduced.

It wrote complete structured findings/probes before its CLI hit the900s host limit; clean CLI completion did not occur.
