## PASS и проверка

Полный список actual V2 GLB и legacy GLB раздельно. Для каждого: найдено/не найдено, путь GLB/.blend/build source/reference, bytes и SHA-256 непосредственно прочитанных файлов. Shared references/helpers дедуплицируются в JSON file catalog. Composite/calibration без независимого concept reference помечаются явно; output screenshots не считаются независимыми references.

Проверка до VERIFY: JSON parse; равенство набора GLB filesystem и записей; существование обязательных source files; повторное вычисление bytes/SHA-256; сравнение с текущим v2 manifest; явные missing/unmapped записи и классификация переиспользования v3. Это инвентаризация, не новый geometry/browser PASS. Никакого Blender, GPU или нового render.

Метод: фактический файл, измерение/расчёт либо meaningful runtime test по конкретному результату. Скрипт/export/отчёт исполнителя сам по себе не закрывает gate.
