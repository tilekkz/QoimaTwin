# QoimaTwin V3 — текущий проверяемый результат

7 ноября2026. Ветка `codex/twin-v3-adaptive`. V3 ещё в разработке; V2 сохранена отдельно.

Готовы модели всех восьми классов груза, отдельные storage-модули, базовый работник/варианты ролей, упаковочный стол, conveyor/environment kit и механическая стадия погрузчика. Это готовность ассетов, не всей сцены и логистики. Близкие виды, реальные метрические размеры, опоры, полости и конечные GLB проверяются отдельно; evidence лежит в этой папке.

В этом продолжении завершены sealed-parcel/tote, LONG rack и24-профильный металлический bundle, DRUM и FRAGILE_CRATE. Добавлены реальные углубления, внутренние стенки, опорные полозья, прокладки, защёлки/петли и контактное затенение стенда. Native fixtures подтверждают размещение без масштабирования и контакты с вилами. Исходные размеры/массы/количество C02 и защищённый backend/общие contracts не менялись.

Проверить модели локально при Node≥22.12:

```powershell
cd frontend
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

Открыть `http://127.0.0.1:4173/stand-v3.html?asset=fragile-crate`. В поле модели можно выбрать `drum`, `long-bundle`, `long-rack`, `sealed-parcel`, `forklift-mast-stage`, `long-rack-loaded-fixture`, `drum-forklift-fixture`, `fragile-forklift-fixture`. Пять ракурсов и свободное вращение/приближение доступны на стенде. Backend для просмотра моделей не нужен.

Следующее: полный цикл погрузчика и LONG attachment, cart/рабочие действия людей, цельная V3-сцена с replay/UX, проверка производительности и отдельный запускаемый V3-пакет. U-cradle в текущих LONG fixtures является геометрическим интерфейсным образцом; полный замок/действия ещё не приняты. Сценарные visual fixtures не являются actual engine run или доказанным улучшением KPI.
