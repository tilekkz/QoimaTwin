# Sources and rights

- Warehouse geometry and IDs: repository v2 specifications and shared contracts,
  preserved as canonical inputs. The visual layer does not modify those schemas.
- Models: original procedural modelling/build scripts for this project. V1 models
  are reused through reviewed local builders; v2 outputs are separate files.
  No downloaded third-party mesh is included in the new set.
- Reference sheets: generated for this project using the built-in image tool;
  their prompts and files are retained under assets/references. User-supplied
  inspiration images were inspected privately and are not republished in the
  night package as freely licensed stock.
- Sound: original procedural oscillators, seeded noise and mechanical ambience;
  no Motionix or unverified commercial recording is redistributed.
- Browser stack: Three.js, Vue, Vite and their relevant MIT license texts are
  included in the delivery's THIRD_PARTY_WEB_LICENSES.txt. No CDN is required.
- Blender 5.0.1 and FFmpeg are locally installed tools, not bundled binaries.
- Existing data/research attribution remains in THIRD_PARTY_NOTICES.md. The
  synthetic visual fixture is not represented as UCI-derived business output.
