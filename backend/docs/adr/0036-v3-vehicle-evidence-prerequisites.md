# ADR 0036: V3 vehicle geometry and declared action-evidence prerequisites

Status: backend proposal; no operational forklift execution is authorized by this adapter.

## Context

Pinned revision `22296bcf2c6bac5ade4cefc7c05c2b97831ec6ec` publishes C08 v0.2,
L07 analytic vehicle motion, L09 local paths, L11 conflicts and L12 compiled
directed arcs. The existing generic `Arc` intentionally represents candidate
distance routing, without physical yaw, pair restrictions or traffic grants.
Manual whole-HU execution remains limited to SMALL/STANDARD jobs.

C08 explicitly sets `actual_model_actions_verified=false` and operational
admission false. A shortest path, broadphase clearance or source support
design does not prove actual fork/HU/support contact or a collision-free action.
No source speeds, lift/reach/steering/reversal durations are provided.

## Decision

Add a separate immutable `VehicleAdapter`, read from six exact SHA-256-pinned
source documents: compiled layout links, layout conflicts, vehicle graph,
vehicle handling, storage slots and fixed port resource policy. All raw bytes
remain available alongside typed projections. The revision and hashes bind
geometry and evidence; this does not repin or change the existing V3 loader.
The caller may supply a complete source root. Reproducible offline repository
use loads the unchanged `data/v3-proposal` base plus the separately pinned
`data/v3-vehicle-proposal` supplement containing the three previously absent
files: conflicts, original vehicle graph and C08 handling. Both provenance
manifests and all six raw file hashes are verified. No download or fallback occurs.

The typed graph retains floor root and front-axle poses, physical yaw,
unwrapped analytic yaw intervals, explicit forward/reverse sign, analytic
straight/rear-steer geometry, both lengths, profiles, cargo and fixed-pair
permissions, source groups and resolved mixed-traffic resources. No implicit
reverse edge, straight-line shortcut, in-place yaw or infinite-width fallback
is created. Numeric endpoint/length consistency uses 1e-9 m absolute and
1e-10 relative floating comparison tolerances solely for serialized source
trigonometric roundoff. These are not physical clearance margins.

Interpolation follows L07 exactly: front axle on a line or analytic signed
ICR curve, floor root 0.40 m behind the axle along physical local +Z. Reverse
motion preserves physical yaw. Original groups and mixed pedestrian/vehicle
traffic cells remain separate source references; no reservation is acquired.
`declared_loaded_arc` intersects C08 eligibility with compiled cargo/profile/
pair permissions; it is a planning restriction check, never a movement grant.

The first local handling gate supports the exact six C08 class design loads,
dimensions and gross masses at source storage supports. It checks static
envelope plus per-side clearance, payload, blocked reserve status, fixed pair
and port class, exact C04 support height, attachment mass and both travel and
extended rating arms about the **fixed chassis** reference. The declared
rating is min(1000 kg, 800 kg·m / arm), each fork ≤500 kg, symmetric CoG only,
and fork top from 0.18 through 1.50 m. It does not infer other loads, module
occupancy, free slots, finite buffer supports, available workers or equipment.

## Proposed evidence envelope

`HandlingRequest` binds HU/cargo, source slot, pair/port, pickup/place, exact
dimensions/mass/fork height and actual model SHA-256 roles: cargo, support,
vehicle, plus attachment where needed. Its digest uses canonical JSON and
exact rational strings. `HandlingEvidence` binds that digest, all source
hashes, the same model hashes and support ID/height. Required proof references
are contact, retention and continuous action, plus lock for attachments. Hashes identify supplied claims;
the adapter does not read meshes or establish those claims from hash equality.

Numeric prerequisites require two distinct fork-indexed contacts at the source
fork X centres, inside the unchanged HU base, exact support Y, fork channels
at least the source 0.08 m width / 0.07 m thickness, plus explicit stage records.
Records have increasing integer microsecond timestamps (ADR0026), reach/fork
height, stopped state and held actor/vehicle/action-space IDs. These are
declared records, not observations generated by a runtime. Test increments
are artificial and are not forklift timing defaults.

Pickup uses stop/reserve → extend high → lower extended → engage → lift
extended → retract high. Placement adds extended withdrawal after release
and before empty lift/retraction, as required by C08. For LONG the request also
requires an attachment model plus two captive-pin and independent restraint
IDs. This evidence is still not an attachment inventory or mounting process.

Missing, mismatched or numerically inconsistent evidence fails closed.
`evidence_complete=true` means the declared envelope passes these bounded
checks. `requires_actual_mesh_verifier=true` and `operational_admission=false`
remain unconditional, including for fully populated evidence. The envelope
is a backend proposal, not a supplied C08 certificate or physical certification.

## Consequences and explicit remaining work

This enables preservation/auditing of source vehicle geometry, exact design
rejections and an explicit interface for later actual contact/action evidence.
It does not execute forklift jobs or widen manual run/export schemas.

Before clocked heavy execution, define loaded/unloaded and forward/reverse
speeds, acceleration, lift/reach/steering/reversal durations and overlap with
source port service; validate buffers and support action geometry; implement
actual mesh/contact/swept-motion verification, exclusive shared traffic grants,
dynamic occupancy, initial driver/vehicle poses, mounting and paid return.
The receiver's participation outside source local port service is unresolved.
The visual frontend pickup fixture is not an equipment duration specification.

Independent tests derive PALLET 455 kg / 227.5 kg per fork, extended 455 kg·m,
IBC 654 kg·m, and rejecting 801 kg at 1 m / 1001 kg nominal / >1.50 m fork top
from source values. Hand geometry verifies analytic curves, not engine-output
goldens. V2 and manual timelines remain outside this patch.
